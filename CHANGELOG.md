## [1.0.0] — 2026-07-25

Первый релиз мобильного клиента. Android, Flutter 3.44.8, внешних зависимостей
нет — только Flutter SDK.

### Интерфейс

- Пять экранов макета Claude Design (`design/SignalAI App.dc.html`), перенесённых
  дословно: дайджест, карточка идеи, журнал, стратегии, настройки.
- График сделки — порт SVG из макета: 44 свечи по тем же опорным точкам,
  диапазон Вайкоффа, ордер-блок, BOS/CHoCH, spring/UTAD, зоны риска и профита,
  пунктиры входа/SL/TP, ценовые чипы на шкале.
- Иконки разобраны из тех же SVG-путей, без перерисовки. Цвета, радиусы,
  отступы и кегли — из `theme/tokens.dart`. Шрифты Jost / Manrope /
  JetBrains Mono вшиты в сборку.
- Подтверждение сделки в один шит, тосты, статус-машина сигнала из ТЗ.

### Автономный режим (анализ на устройстве)

- Скринер первой ступени из ТЗ §5.1 целиком: RSI(14) Уайлдера с дивергенциями,
  фрактальные свинги и структура рынка (BOS/CHoCH), FVG, свечные триггеры
  (пин-бар, поглощение, внутренний бар), z-оценка объёма, дельта открытого
  интереса, фандинг, ATR, режим рынка по индексу, валюте и биткоину.
- SignalScore по весам ТЗ §5.3. Блока LLM-вердикта (15 из 100) на устройстве
  нет, поэтому итог нормируется на сумму доступных весов: буквальный порог 85
  из ТЗ §12 иначе был бы недостижим. Порог показа — 60, порог «пуша» — 75.
- Уровни: вход — ретест сломанного уровня, стоп — за противоположным
  экстремумом с буфером в половину ATR(1H), тейки — 1,4R / 2,2R / 3,5R долями
  50/30/20. Отбраковка по дальности входа, нереалистичному стопу, R:R до TP2
  ниже 1,5, экспирации ближе трёх дней и нехватке истории; причины копятся
  в `lastRejections`.
- Клиенты рыночных данных: MOEX ISS и публичный Bybit. Пагинация ISS по
  курсору `start` с предохранителем по числу страниц, возраст котировки
  считается по московскому времени и проверяется только внутри торговой сессии
  (будни 09:00–23:50 MSK).
- Никаких тихих подмен таймфрейма: если биржа не отдаёт запрошенный интервал
  (10 минут у Bybit, 4 часа у ISS), клиент бросает `ArgumentError`. Свеча с
  неразобранной датой отбрасывается, а не датируется текущим временем.

### Режимы и конфигурация

- `--dart-define=SIGNALAI_MODE=local|demo`, по умолчанию `local`. Заданный
  `SIGNALAI_API_BASE_URL` всегда выигрывает и переводит приложение в режим
  тонкого клиента серверного гейтвея.
- Депозит и риск на сделку редактируются в разделе «Риск-профиль», объёмы
  позиций пересчитываются во всём приложении.

### Ключи и подпись

- Ключей бирж и брокеров в сборке нет: всё, что попадает в APK через
  `--dart-define`, извлекается из него за минуту. Аналитике ключи и не нужны —
  MOEX ISS и публичные эндпоинты Bybit работают без авторизации.
- Релизная подпись — из GitHub Secrets, keystore создаётся локально
  (`tool/make_keystore.sh`). Сборка без секретов подписи падает намеренно:
  отладочный ключ означает блокировку Play Protect.
- CI `.github/workflows/android-release.yml` собирает AAB и APK по тегу `v*`
  или вручную, проверяет подпись через `apksigner` и удаляет ключ из рабочей
  директории.

### Проверки

`flutter analyze` — чисто, `flutter test` — 59 тестов проходят.

### Чего в этой версии нет

Экранов Watchlist (сигналы 60–74) и «Отчёт дня», биометрии на подтверждение,
пушей FCM, kill switch. Локальный бэктест не реализован — `runBacktest` в
автономном режиме честно бросает `UnimplementedError`. Дайджест по расписанию,
сопровождение позиций, Telegram/MAX и вторая ступень LLM требуют серверного
контура: Android не даёт держать живой фоновый процесс.

Клиенты `IssClient` и `BybitClient` ни одного реального ответа биржи ещё не
видели — в контейнере разработки `iss.moex.com` и `api.bybit.com` закрыты
сетевой политикой. Разбор ответов и пагинация покрыты тестами на фикстурах
(`test/market_test.dart`), но сверку с живым API нужно провести на устройстве.
