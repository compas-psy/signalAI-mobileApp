# SignalAI — мобильный клиент

Android-приложение личного терминала торговых идей: утренний дайджест, карточка
идеи с графиком в стиле TradingView, подтверждение сделки, журнал, стратегии и
настройки.

Реализация макета из Claude Design (`design/SignalAI App.dc.html`) на Flutter,
по ТЗ «SignalAI — персональная система торговых сигналов и исполнения» v1.0.

## Что это и чего это не делает

Приложение — **тонкий клиент** (ТЗ §2). Оно:

* показывает готовые сигналы, позиции, журнал и статистику;
* даёт подтвердить сделку одним касанием;
* переключает стратегии, каналы доставки и параметры риска.

Оно **не**:

* хранит ключи бирж и брокеров — их нет на устройстве вообще (ТЗ §11);
* считает аналитику — Wyckoff/SMC/RSI/объём/OI и SignalScore считает сервер;
* торгует само — любой ордер только после явного подтверждения (ТЗ §7).

Аналитика по биржевым API (MOEX ISS + Т-Инвестиции, Bybit) и доставка в
Telegram/MAX живут на сервере. Какие ключи где прописать — `docs/SECRETS.md`.

## Запуск

```bash
flutter pub get

# демо-режим на данных макета, без сервера
flutter run

# с реальным гейтвеем
flutter run --dart-define=SIGNALAI_API_BASE_URL=https://ваш-гейтвей
```

Без `SIGNALAI_API_BASE_URL` приложение поднимается на фикстуре из макета и
полностью кликается офлайн — удобно смотреть интерфейс.

Проверки:

```bash
flutter analyze
flutter test
```

## Сборка для телефона

Подпись обязательна: Play Protect блокирует сборки с отладочным ключом.

```bash
./tool/make_keystore.sh                       # один раз, локально
flutter build apk --release --dart-define=SIGNALAI_API_BASE_URL=https://…
```

Подробно, включая CI и внутреннее тестирование Play — `docs/ANDROID_SIGNING.md`.

В CI две сборки, и путают их часто:

| Workflow | Когда идёт | Подпись | Для чего |
|---|---|---|---|
| `android-sideload.yml` | каждый пуш в любую ветку, плюс кнопка | отладочная | поставить себе на телефон прямо сейчас, ничего не настраивая |
| `android-release.yml` | тег `v*`, плюс кнопка | своим ключом из GitHub Secrets | Play Console и раздача наружу |

Sideload-сборке секреты не нужны вообще. Релизная без них падает намеренно:
отладочная подпись — прямой триггер блокировки Play Protect. Поставить релиз
поверх sideload-сборки не выйдет (тот же `applicationId`, другая подпись) —
сначала удалить старую.

## Структура

```
lib/
  main.dart              точка входа, выбор репозитория (сервер или демо)
  theme/                 токены макета: цвета, радиусы, типографика
  core/format.dart       форматирование чисел (узкий пробел, запятая, U+2212)
  domain/                модели и перечисления предметной области
    enums.dart           направление, горизонт, рынок, статус-машина сигнала
    models/              сигнал, позиции, журнал, стратегии, настройки
    position_sizing.dart расчёт объёма для отображения
  data/
    repository.dart      контракт данных
    api/                 HTTP-клиент и REST-реализация (docs/API.md)
    mock/                данные макета для демо-режима
  state/                 контроллер приложения и доступ к нему
  ui/
    app_shell.dart       каркас: экран, навигация, шит, тост
    screens/             пять экранов макета
    widgets/             график, спарклайн, кольцо скора, иконки, шит, тост
design/                  исходный экспорт макета (ТЗ §9)
docs/                    API, секреты, подпись Android
```

Внешних зависимостей нет — только Flutter SDK. В приложении, которое подтверждает
сделки, чем меньше стороннего кода, тем лучше.

## Соответствие макету

Перенесено дословно, а не «на глаз»:

* график сделки — порт SVG из макета: те же 44 свечи по тем же опорным точкам,
  диапазон Вайкоффа, ордер-блок, BOS/CHoCH, spring/UTAD, зоны риска и профита,
  пунктиры входа/SL/TP и ценовые чипы на шкале (`ui/widgets/trade_chart.dart`);
* иконки — разбор тех же SVG-путей (`ui/widgets/svg_path.dart`), без перерисовки;
* цвета, радиусы, отступы и размеры шрифтов — из `theme/tokens.dart`;
* шрифты Jost / Manrope / JetBrains Mono вшиты в сборку.

Что сознательно отличается от прототипа:

* панель Tweaks стала редактируемыми полями «Депозит» и «Риск на сделку» в
  разделе «Риск-профиль» — объёмы позиций пересчитываются во всём приложении;
* статус идеи (`Новая` / `В работе`) считается по статус-машине сигнала из ТЗ,
  а не по локальному флагу;
* доли фиксации по тейкам приходят с сервера. В макете и демо-данных 50/30/20,
  в ТЗ §6.5 как дефолт указано 40/40/20 — значение задаётся конфигом стратегии.

## Что ещё не сделано

Из ТЗ §9 в этой версии нет экранов Watchlist (сигналы 60–74) и «Отчёт дня», нет
биометрии на подтверждение, пушей FCM и красной кнопки kill switch. Каркас под
них есть: статусы, репозиторий и модели это учитывают.

## Дисклеймер

Аналитика, а не индивидуальная инвестиционная рекомендация. Торговля фьючерсами
и криптовалютой с плечом несёт риск потери всех средств. Система действует
только по подтверждению владельца счетов.

## Режимы работы

Выбираются при сборке: `--dart-define=SIGNALAI_MODE=local|demo` (по умолчанию
`local`). Если задан `SIGNALAI_API_BASE_URL`, он всегда выигрывает и приложение
работает как тонкий клиент сервера.

| Режим | Откуда данные | Ключи | Ограничения |
|---|---|---|---|
| `local` | MOEX ISS + публичный Bybit, скринер считается на устройстве | не нужны | анализ при открытии приложения, без расписания и сопровождения позиций |
| `server` | мобильный гейтвей Server B | на сервере | нужен серверный контур из ТЗ §2 |
| `demo` | фикстура макета | не нужны | цифры нерыночные |

### Что делает автономный режим

Скринер первой ступени из ТЗ §5.1 целиком: RSI(14) Уайлдера с дивергенциями,
фрактальные свинги и структура рынка с BOS/CHoCH, FVG, свечные триггеры
(пин-бар, поглощение, внутренний бар), z-оценка объёма, дельта открытого
интереса, фандинг, ATR и режим рынка по индексу, валюте и биткоину.

SignalScore собирается по весам ТЗ §5.3. Блок LLM-вердикта (15 из 100) в
автономном режиме отсутствует, поэтому итог **нормируется на сумму доступных
весов**, а не занижается на 15 пунктов: иначе ни один сигнал никогда не прошёл
бы порог. Порог показа — 60, порог «пуша» — 75.

Уровни строятся так: вход — ретест сломанного уровня, стоп — за противоположным
экстремумом с буфером в половину ATR(1H), тейки — 1,4R / 2,2R / 3,5R долями
50/30/20. Кандидат отбраковывается, если вход дальше 0,5·ATR от цены, стоп
нереалистичен, R:R до TP2 меньше 1,5, до экспирации меньше трёх дней или мало
истории. Причины отбраковки не теряются — они копятся в `lastRejections`.

### Чего автономный режим не умеет

Дайджест в 10:10 и мониторинг позиций каждые 5 минут требуют постоянно
работающего процесса — Android глушит фон (Doze, лимиты background work).
Исполнение ордеров, реальные остатки и ГО, Telegram/MAX, LLM-разбор второй
ступени — всё это появляется только с серверным контуром либо с ключами
брокера, введёнными в приложении.
